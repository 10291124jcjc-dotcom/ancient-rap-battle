# 踩坑清单（都已写进脚本的默认规则）

| 坑 | 表现 | 解决 |
| --- | --- | --- |
| 参考图用全身三视图 | H3 拍成全身远景，脸小，看不清口型 | 近景用裁出来的半身图，提示词第一句写景别 |
| 一条给两句歌词 | 第 2 秒后 H3 自己重唱，嘴对不上 | 一条只给一句 |
| H3 把歌晚放 0.1–0.3 秒 | 自动检查看起来全红 | qa.py 先整句搜偏移，h3run 自动存进 shifts.json |
| 纯侧脸、麦克风挡嘴 | 口型看不出 | 唱的人 3/4 侧脸，麦拿低 |
| 说唱时手里没麦 | 穿帮 | 提示词写明右手始终拿麦 |
| 圈里站一排群演 | 像士兵列队 | 写明圈里不站人 |
| 道具变形（羽扇变折扇） | 前后不一致 | 尾部写死道具材质和形状 |
| 观众镜头台上是空的 | 对唱时台上没人 | M10 写明两人在圈里、谁在唱 |
| 气氛组出现太多 | 群演抢戏 | 全片最多 3 次 |
| 同一个镜头切三段连放 | 一卡一卡 | 中间插别的镜头 |
| 按嘴型测量结果挪画面 | 有一次挪 0.58 秒反而错 | lipcheck 只作参考，挪完给用户看，说原来对就改回 |
| 字幕提前 | 每句早 0.4–0.8 秒 | 句起点只算落在本小节的字，跳过上一句溢出的尾字 |
| 识别在前奏里幻听出字 | 歌词段落找错位置 | 用前 4 句歌词去匹配识别文字定位 |
| 调色太重 | 成片暗 30% | 只加一点对比和颗粒 |
| 本地改口型（LatentSync） | 装得上，但用户觉得不如原版 | 不用 |
| 发文件到手机 | 超过 30MB 只能在电脑上看 | package.py 同时出手机预览版 |
| ffmpeg drawtext 崩溃 | 缺 fontconfig | 文字全用 Pillow 画成 PNG 再叠 |
| Windows 上 `python3` | 是微软商店占位程序 | 用 `python` |
